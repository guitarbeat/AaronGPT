# AaronGPT — Complete Pixel Brand Kit

**Start with:** `00_START_HERE/brand_kit_preview.png` for the visual index.

This set is built around the approved AaronGPT artwork and the supplied **Proof** character references (warm brown skin, long dark locs, rectangular eyes, expressive brows, white lab coat, purple shirt, and thumbs-up). All principal exports use the same logo artwork, not different model-generated reinterpretations.

## Folders

- `01_LOGOS/`: primary square logo, transparent logo, text-only wordmark, icon-only and wide lockup.
- `02_AVATARS_FAVICONS/`: ready-to-use profile and app icons, tiny monogram favicon, `.ico` file.
- `03_SOCIAL_WEB/`: Open Graph card, website hero, social header, YouTube cover, square post, vertical story.
- `04_PROOF_MASCOT/`: actual transparent thumbs-up sprite, sticker, alternate high-resolution portrait cutout.
- `05_BACKGROUNDS/`: desktop and phone wallpapers, repeating pattern tile and preview.
- `06_UI_ELEMENTS/`: pixelated button designs, chat icon, sparkle, status badge.
- `07_SOURCE/`: source logo and supplied reference images for future editing.

## Usage notes

- Transparent PNGs have an alpha channel. Tiny favicon graphics use a deliberate simplified monogram for readability.
- Keep logo aspect ratios intact, keep generous clearance around emblem, and avoid smoothing when scaling. In CSS, use `image-rendering: pixelated;`.
- The cream knot should not cover Proof's locs or coat, and the amber sparkle remains a single accent.
- Use the black or dark-plum backgrounds as default. Avoid gradients, glow effects and rounded modern UI styling if preserving the 8-bit character.
- This is satirical original project branding; don't suggest it is an official OpenAI product.
- The large teal-background portrait cutout is provided as an alternate reference; the thumbs-up sprite is the faithful actual pose source.
